Audio Converter

Chuyển đổi định dạng file âm thanh bằng ffmpeg: mp3 ↔ ogg ↔ wav ↔ m4a ↔ flac ↔ opus. Chạy hàng loạt, đổi sample rate, gộp về mono, chuẩn hoá âm lượng và cắt khoảng lặng đầu/cuối.

1. Files

Kéo file âm thanh hoặc thư mục từ panel Assets thả vào đây, hoặc dùng các nút bên dưới.
Add selected in Assets Browse files... Clear list

2. Output format

kbps
64 96 128 192
MP3: 0 = tốt nhất, 9 = nhỏ nhất

3. Audio settings

Chuẩn hoá âm lượng về -16 LUFS. Chậm hơn vì phải phân tích cả file. Cắt khoảng lặng ở đầu và cuối. Hữu ích cho SFX cần phát tức thì.

4. Output

...
Xoá file gốc (và .meta của nó) sau khi convert xong. Chỉ bật khi bạn đã hiểu cảnh báo về uuid bên dưới. Cho phép mp3 → mp3 (để hạ bitrate / đổi sample rate). Mặc định các file đã đúng định dạng sẽ bị bỏ qua. Chép file gốc + .meta vào temp/audio-converter-backup/<timestamp> trước khi chạy.
Lưu ý về uuid: đổi đuôi file nghĩa là Cocos tạo asset MỚI với uuid mới. Mọi chỗ đang gán AudioClip cũ trong scene/prefab sẽ bị mất tham chiếu và bạn phải gán lại tay. Muốn giữ nguyên tham chiếu thì đừng đổi định dạng — chỉ hạ bitrate bằng Re-encode same format.
